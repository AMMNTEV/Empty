About

Empty — a temporary web messenger without registration. No emails, phone numbers, or passwords on the server.

Identity. On first launch, a cryptographic key pair (X25519 + Ed25519) is generated. It is stored only on your device, encrypted with a password.

How to connect. Exchange cards via QR code. Scan — a contact appears. No username search.

Messages. Encrypted with AES-GCM using a shared X25519 key. The server only sees ciphertext and metadata.

Chats live 24 hours. Each new message resets the timer. If you don't write for a day, the chat is deleted for both. Can be ended manually.

Files. All history is stored locally in the browser's OPFS, encrypted. Clear browser data — lose everything.

Features:

  • Multi-account on one device
  • Import from another device (QR + temporary password)
  • QR card scanner

Cryptographic strength. Key space — 2256. Brute force at 109 keys/sec would take ~1060 years. Even with a quantum computer (√N = 2128) — astronomically long.
